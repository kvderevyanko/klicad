# ESP32 + LoRa ground receiver

Проект реальной печатной платы наземного LoRa-приёмника на
ESP32-WROOM-32E и EBYTE E220-900T22D. Цель — электрически корректное и
изготовляемое устройство, а не демонстрационная схема.

## Текущий статус

Завершены Requirements и Stage 2 (проверка компонентов). Принципиальная схема,
PCB и производственные файлы ещё не создавались.

Перед началом schematic должны быть решены остающиеся инженерные вопросы:

- точный OLED-модуль, его питание и ток;
- USB-C receptacle, подтверждённый source-current target и входная защита;
- антенна, регион и допустимые настройки E220;
- верифицированные land pattern для E220-900T22D и WS2812B-V5;
- механика платы, крепёж и габариты.

## Принятые решения

- MCU: `ESP32-WROOM-32E-N4`, без PSRAM.
- Радиомодуль: `EBYTE E220-900T22D`, питание от защищённой 5 V шины.
- UART E220: GPIO17 принимает TXD, GPIO16 передаёт в RXD. GPIO15 исключён,
  поскольку это strapping pin ESP32.
- 3.3 V: `TPS62162DSGR`.
- Статусный LED: `WS2812B-V5` от 5 V через `SN74AHCT1G125DBVR`.
- Прошивка: внешний 3.3 V UART0 adapter, отдельные кнопки BOOT и RESET.
- USB-C: только вход питания; USB data и встроенный USB-UART отсутствуют.

## Структура

- `.codex/agents/pcb-engineer.toml` — профиль специализированного инженера по
  электронике и PCB.
- `agents.md` — правила работы с проектом и журнал существенных изменений.

## Инженерные правила

Для работ по схеме и PCB используется профиль `pcb_engineer`. Критические
параметры, pinout, footprint и требования RF берутся только из официальной
документации производителей. Все постоянные файлы проекта создаются только в
этом каталоге и его подкаталогах.

Подробный статус и источники приведены в [документации](docs/requirements.md).
