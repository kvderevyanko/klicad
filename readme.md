# Несущая плата ESP32 + E220, Rev.1

Текущая Rev.1 — **кандидат для предсерийной проверки**, а не производственный выпуск. Электрическая схема и трассировка завершены: 37 посадочных мест, 200 дорожек, 58 переходных отверстий, четыре медные зоны, два слоя, контур 145 × 90 мм; ERC, native DRC, соответствие схемы/платы и контракт платы проходят без ошибок и без неподключённых объектов.

## Действующая архитектура питания

\`BAT_PLUS → F1 → BAT_FUSED → J8.1 → внешний выключатель → J8.2 → BAT_SW → Q1 → BUCK_IN → TPS62133 → 5V_SYS\`.

\`D3 SMBJ10CA\` подключён между \`BAT_FUSED\` и GND. У Q1 \`DMP3130LQ-7\`: 1=\`Q1_GATE\`, 2=\`BUCK_IN\`, 3=\`BAT_SW\`.

\`5V_SYS → JP1 → VIN ESP32 DevKit\`. Обычный режим: выключатель включён, JP1 замкнут. Для сервисного USB с изоляцией: выключатель выключен, JP1 разомкнут при необходимости; JP1 не является автоматической изоляцией доменов.

\`5V_SYS → U4 TLV1117LV33 → AUX_3V3 → OLED\`. OLED питается только от \`AUX_3V3\`; \`DEVKIT_3V3\` не является питанием аксессуаров.

## Узлы и сборка

- J1/J2 — заводски устанавливаемые розетки ESP32; сам ESP32 DevKit устанавливает пользователь.
- J3 — заводски устанавливаемая розетка Samtec для одного пользовательского E220-400T22D или E220-900T22D; антенна обязана соответствовать диапазону модуля.
- J5 — заводски устанавливаемая розетка OLED; механическая совместимость конкретного OLED подтверждается на первом образце.
- J6 \`BUTTONS\` и J9 \`RGB OUT\` — пользовательские DNP-интерфейсы.
- D2, J7 и TP6…TP10 отсутствуют. TP1…TP5 — сохранённые металлизированные пробные отверстия без устанавливаемого компонента.

Электрические соединения завершены. Крепёж и разгрузка аккумуляторного кабеля сознательно отложены до корпуса/жгута или Rev.2. Генерация Gerber, сверловки, производственного BOM и CPL разрешается только отдельной задачей после предсерийного ревью.
