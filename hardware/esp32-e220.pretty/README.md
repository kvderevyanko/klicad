# Rev.1 project-local footprint library

This is a reproducible Stage 7/8 library, generated by
`hardware/generate_stage7_footprints.py`. It supports the separate,
un-routed Stage 8 functional-placement board generated by
`hardware/generate_stage8_placement.py`; it does not authorize routing or
production release. The active Rev.1 power
architecture is battery-only: protected external 2S Li-ion input → input
protection → TPS62133RGT → `5V_SYS`. Old carrier USB-C footprints/architecture
are superseded and intentionally absent.

## Interfaces

- `JST_B2B-XH-A_1x02_P2.50mm_THT`: carrier `BAT+`/`BAT-` input, exact JST XH
  B2B-XH-A geometry; mating harness `XHP-2` / `SXH-001T-P0.6`.
- `Samtec_SSW_1x15_P2.54mm_THT` (two), `...1x07...`, `...1x04...`: selected
  SSW-115/107/104-02-G-S carrier sockets. Official Samtec SSW-S layout fixes
  pitch 2.540 mm and drill 1.040 mm; 1.70-mm copper is an explicit project
  annular-ring choice pending assembler confirmation.
- `ESP32_DevKit_30pin_Socket_2x15_MechanicalTemplate`: only two 1x15 rows at
  p=2.540 and 25.400-mm centre spacing are verified. The 28 x 51-mm body is
  USER-MEASURED and unregistered to the header datum.
- `E220_T22D_Socket_400_900`: carrier socket (not EBYTE solder pads), using the
  common 21 x 36-mm / 1x7 p=2.540 geometry. 400-MHz and 900-MHz antennas are
  not interchangeable. Official EBYTE 400/900-T22D drawing plus 900 STEP/LIB
  confirm the common pin row, SMA-side envelope and fixing-hole guide sites;
  holes 8…10 are guides only, not carrier contacts/NPTH. Validate the selected
  socket's mating insertion on a first article before PCBA release.
- `OLED_0p96_4pin_MechanicalTemplate_PENDING_DATUM`: active removable OLED
  interface is 1x4 p=2.540, GND/VCC/SCL/SDA. User data fixes body 26.000 x
  26.000 and mount-centre spacing 21.740 x 22.000 mm, plus GND/VCC/SCL/SDA
  pin-X values 9.190/11.730/14.270/16.810 mm from the left edge. Header-row Y
  and hole diameter remain unverified; no NPTH is created.

## Active power components

`TI_TPS62133RGT_RGT0016C`, `Coilcraft_XFL4020-222MEB`,
`Diodes_DMP3130LQ-7_SOT23`, `Littelfuse_1812L200_16_4532Metric`,
`Littelfuse_SMBJ10CA_DO214AA`, and the named Murata case footprints are
project-local audited footprints. The TPS62133 EP footprint is distinct from
the later thermal-via / EMI placement rules: it uses TI RGT0016C's 1.680-mm
EP copper with a 1.550-mm (~85%) official stencil aperture.

`TI_SN74AHCT1G125DBVR_SOT23-5` is a functional placement footprint for the
on-board 5-V level shifter, still subject to final MPN-specific PCBA audit.
`WorldSemi_WS2812B-V5_PLACEMENT_CANDIDATE_NOT_RELEASED` intentionally makes
the selected status LED visible during placement but is **not** a production
land pattern: the project still needs auditable WorldSemi pad-pattern evidence
before fabrication. `TestPoint_THT_1p0mm_PROTOTYPE` is an explicitly
provisional 1.0-mm-drill prototype test-point land, pending test-point MPN and
assembler selection.

Read `docs/footprint-mechanical-review.md` for sources, exact recorded pad and
drill values, and release blockers. Factory PCBA populates carrier parts only;
the ESP32 DevKit, E220 and OLED are user-installed.

## Preliminary placement policy

The current Stage 8 board has real carrier footprints/nets but is **unrouted**:
28x51-mm DevKit, 21x36-mm E220 and 26x26-mm OLED envelopes are separated by at
least 5 mm, with more room for removal and external access. The preliminary
145x90-mm outline is a comfortable proposal, not a final outline. The DevKit
antenna end remains a no-components/no-routing edge placeholder, and the
DevKit USB-C / E220 SMA must remain accessible. OLED-A header-row Y and OLED-B
finished hole diameter block only its production mounting pattern; routing and
production release remain separately gated by reviewer approval.
